Lévitad — Gestión

Inicia sesión con tu token de GitHub para administrar el catálogo. Solo tú y los autorizados deben tener este token.

¿Cómo crear el token?
  1. Entra a github.com/settings/personal-access-tokens → Generate new token (fine-grained).
  2. Repository access: Only select repositories → marca cuellar-dev/limbo.
  3. Permissions → Repository → Contents: Read and write.
  4. Pon una expiración corta (ej. 90 días). Copia el token y pégalo aquí.
Nunca compartas el token ni lo subas a otro sitio. Si lo expones por error, ve a la misma página de GitHub y revócalo.
